# 暴富幻想所微信小游戏真机预览

这是用于手机微信里直接体验核心链路的最小小游戏壳。

## 打开方式

1. 打开微信开发者工具。
2. 选择「小游戏」项目。
3. 导入目录：`wechat-game/`。
4. AppID 暂用「测试号 / touristappid」。如果你有真实 AppID，可以在 `project.config.json` 里替换。
5. 工具里点击「预览」，用手机微信扫码。

## 当前可体验内容

- 第一关 `键盘声变轻了`。
- 开局消耗今日体力。
- 点击真实线索收集进度。
- 错点 3 次后失败。
- 看广告复活、复活卡复活、分享复活。
- 体力耗尽后看广告加体力。
- 通关后显示今日目标进度和连胜记录。
- 分享战报、广告翻倍提示券。
- 分享链接进入后按 `reward` 领取提示券或复活卡，并用 `assist` 去重。

## 当前限制

- 这是 Canvas 原生预览壳，不是完整 Web/Vite UI 的移植。
- 目前只接第一关，后续再迁移全部关卡。
- 广告位使用占位 placement；没有真实广告单元 ID 时会自动走本地完成 fallback。
- 排行榜、连胜和分享归因仍是本地状态模拟，不是服务端权威数据。
