# Convenience Level Production Brief

Scene: `convenience` / lottery-store convenience scene

Status: playable Phaser level with seven clues. This level is the baseline for the later hidden-object direction: visible physical objects, believable clutter, and delayed semantic association.

## Theme

Small-ticket gambling pressure: a convenience-store lottery corner makes "almost won" and "easy next try" feel ordinary enough to ignore the cost.

## Scene Logic

The scene is a crowded convenience/lottery counter. The owner, customer, rider, tickets, drinks, posters, counter glass, payment objects, and small notes must all make sense in that retail environment. This level should not rely on arbitrary handwritten answer labels.

## Clue And Difficulty Plan

This is level 3 and must increase after rooftop:

- 7 clues, increasing from 6.
- The best clue bodies are physical object relationships: waste tickets, covered amount, misleading counter position, drink/counter temptation, and ordinary retail clutter.
- Text can exist on tickets, posters, and notes, but the answer should not be "click every text area".
- True clues need ordinary nearby decoys: regular scratch tickets, drinks, receipts, QR/payment signs, notes, shelves, and counter items.

## Character State Plan

Use `convenience-progress-0` through `convenience-progress-7` or a better same-camera replacement. Progress must visibly alter Zhou Qiming's expression/posture, not only the evidence board.

## Rejection Gates

- no numbered answer labels baked into the image
- no clue target so broad that any ticket in a row counts
- no pure text explanation such as "this one is fast" without object support
- no phone/card object that cannot be read as its stated role
- no hotspot drift after final raster freeze
